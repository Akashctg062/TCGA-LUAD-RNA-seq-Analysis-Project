Welcome to the TCGA-LUAD RNA-seq Analysis Project repository, which features a retrospective computational bioinformatics pipeline designed to identify novel prognostic biomarkers in Lung Adenocarcinoma by integrating transcriptomic data, weighted gene co-expression network analysis (WGCNA), and immune infiltration profiling. This repository currently contains the core project components, including the primary omics data, analysis results data, Python code scripts, environment requirements, and this readme. If you require access to other detailed files or need additional data not provided in the public repository (such as venv, geo, multiomics, pancancer, geneid mapping, PCA, node_modules), please feel free to request it by reaching out to me via email at akashctg062@gmail.com or d825114001@tmu.edu.tw.
